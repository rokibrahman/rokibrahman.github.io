Mr. Raven: Privacy Policy

Last updated: October 21, 2026

Mr. Raven is a private, self-hosted assistant used by a single person, its owner. This policy explains what Google user data the application accesses and how that data is handled.

1. Who uses this application

Only the owner. Mr. Raven is not offered to the public, and no other person's Google account is connected to it.

2. Data accessed

  • Gmail messages and metadata (read-only scope gmail.readonly): used to summarise and prioritise the owner's inbox and to find tasks and deadlines.
  • Gmail drafts (scope gmail.compose): used only to create draft replies, which the owner reviews and sends himself.

3. How data is used

  • Only to provide the features above to the owner.
  • To produce summaries and drafts, message content is sent to large-language-model APIs (Anthropic and Google AI) for processing. It is not sold, shared, or used for advertising.
  • Google user data is not used to develop, improve, or train generalised AI or machine-learning models.

4. Storage and security

  • Data is processed on a private server controlled by the owner. Access tokens are stored there with owner-only file permissions.
  • Summaries, tasks and logs are kept only as long as the owner needs them, and the owner can delete them at any time.
  • No human other than the owner has access to the data.

5. Sharing

Google user data is not shared with, transferred to, or sold to third parties. The only exception is the model-API processing described in section 3, done solely to provide the features to the owner.

6. Limited Use disclosure

Mr. Raven's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
